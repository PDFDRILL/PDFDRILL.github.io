pdfdrill – skill card

Purpose: Convert PDFs into structured, evidence‑backed document objects for LLM use.

Ingestion

  • Converts PDFs into math, geometry, images, tables – not just plain text.
  • Optimal OCR route: Mathpix → lines.json.
  • Alternative OCR: Gemma4 26B hosted → Mathpix‑compatible lines.json.
  • Binary PDFs: pdfminer.six (math‑extended) → lines.json‑like output.

Document object functions

  • Transclusion of all math expressions.
  • Translation of transcluded text (e.g. Chinese ↔ English).
  • Bibliographic aggregation via Perplexity.ai search.
  • Paragraph‑level conceptual summaries.
  • Spoken math rendering.

Output projection

  • Markdown
  • LaTeX
  • LLMtext – token‑optimised math for LLMs.

Evidence reports (most important)

  • HTML inspect – element tree with region highlighting.
  • HTML formula tables – LaTeX source · KaTeX render · MathPix crop.
  • PDF residual table for math (inkdrill compare) – geometry‑based ink comparison between rendered LaTeX and original PDF.

Goal: the user can see exactly where to look or correct; geometry is the basis for comparing rendered ink to original ink.
