01 — ingestion

Three routes in, one shape out.

Whatever the PDF, ingestion ends in lines.json — page geometry plus recognised text and math — so everything downstream works the same way.

Optimal OCR route

MathPix→lines.json

The best-quality route for math.

Alternative OCR

Gemma 4 26B→lines.json

Hosted model, MathPix-compatible output.

Binary PDFs

pdfminer.six→lines.json-like

Math-extended pdfminer.six reads the text layer directly.

02 — document object functions

Operate on the object, not the text.

Transclusion

Every math expression is held once and transcluded wherever it is used.

Translation

The transclusions map all non-textual elements to text that is not changed by an automatic translation via DeepL.com.

→ worked ZH → EN example

Bibliographic aggregation

References resolved and aggregated via Perplexity.ai search.

Conceptual summaries

A conceptual summary for each paragraph.

Spoken math

Formulas rendered as speakable text.
